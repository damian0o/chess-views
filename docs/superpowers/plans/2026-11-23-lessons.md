# Lessons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Guided lessons that walk a kid through the app's views step by step, with locked tabs, hidden-answer steps, saved progress on the device, and the Scholar's mate as the first lesson.

**Architecture:** `lessons.js` is a pure module (step resolution, gates, open views, bold parsing, the progress store with injected storage) covered by node tests. `positions.json` gains a `lessons` array validated by the library test. `index.html` adds lesson state, a step bar between the tabs and the status line, lesson-aware tabs and library shelf, and `lesson`/`step` in the hash. Browser checks move into the repo under `tests/browser/` with a runner, and the lessons check is the extended pass.

**Tech Stack:** Plain ES modules, chess.js 1.0.0 (CDN, already used), `node --test`, Python Playwright for the browser checks.

**Spec:** `docs/superpowers/specs/2026-11-23-lessons-design.md`

## Global Constraints

- Static page, no build step, no new runtime dependencies. `lessons.js` is imported by `index.html`, so it joins `ASSETS` in `scripts/stamp.js` and `npm run stamp` runs before every commit that touches it.
- `positions.json` keeps its hand-formatted one-entry-per-block style; lesson steps are one object per line or small block.
- Copy: sentence case, at most two sentences per step, `say` ≤ 220 characters, the view's name in `**bold**` the first time a step asks for it. Button texts exactly: `Next ▶`, `◀ Back`, `Finish ✓`, `Open <View> first`, `Press ▶ first`, `Press Reveal pieces first`, `Start`, `Continue`, `Start over`. Toasts exactly: `Finish the lesson to open this`, `Lesson finished`, `That lesson is not here`.
- Saved progress: `localStorage` key `chess-views:lessons`, value `{ "<id>": { "step": <1-based highest step reached>, "done": boolean } }`; every read and write in try/catch; nothing else stored.
- Existing links (`#pos=`, `#fen=`, `#pgn=`, `view`, `sq`, `flip`, `eval`, `solve`) behave as before when `lesson` is absent.
- Branch `lessons`; commit messages end with the session's attribution lines; merge `--no-ff` into `main` only after the full browser pass is green locally.

## Review Focus

1. A step that points at a library entry (`pos`) must use the step's own view and square, not the entry's. Pinned by a `resolveSteps` test in Task 2.
2. A reload in the middle of a lesson while the kid is in the wrong view must keep Next disabled and leak nothing. Pinned by the reload check in Task 4.
3. Going Back onto a `solve` step after its reveal must hide the moves again at the step's ply. Pinned by the Back check in Task 4.
4. A browser whose storage throws (quota, private mode) must run the lesson exactly as without storage, with no error. Pinned by the throwing-storage unit test in Task 1 and the browser check in Task 6.
5. A link with an unknown lesson id or a step out of range must not break the page: a toast and the normal start position. Pinned by the bad-link check in Task 4.

### Task 1: `lessons.js` — bold parsing and the progress store

**Files:**
- Create: `lessons.js`
- Test: `tests/lessons.test.js`
- Modify: `scripts/stamp.js` (`ASSETS` gains `'lessons.js'`), `tests/stamp.test.js` title mentions it.

**Interfaces:**
- Produces: `sayParts(say: string) -> Array<{ text: string, strong: boolean }>` — splits on `**…**`; no other markup.
- Produces: `progressStore(storage) -> { get(id) -> { step, done } | null, set(id, { step, done }) -> void, reset(id) -> void, all() -> object }` — `storage` is anything with `getItem`/`setItem`/`removeItem` (the browser passes `localStorage`); every call is wrapped in try/catch and a throwing or missing storage makes `get` return null and `set`/`reset` no-ops; `set` never lowers `step` and never clears `done` (`reset` does both).
- Produces: `PROGRESS_KEY = 'chess-views:lessons'`.

- [ ] **Step 1: Write the failing tests**

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { sayParts, progressStore, PROGRESS_KEY } from '../lessons.js';

test('sayParts splits bold runs and leaves the rest alone', () => {
  assert.deepEqual(sayParts('Open **King houses**. Only the king guards f7.'),
    [{ text: 'Open ', strong: false }, { text: 'King houses', strong: true }, { text: '. Only the king guards f7.', strong: false }]);
  assert.deepEqual(sayParts('No bold here'), [{ text: 'No bold here', strong: false }]);
});

const memory = () => { const m = new Map(); return { getItem: (k) => (m.has(k) ? m.get(k) : null), setItem: (k, v) => m.set(k, v), removeItem: (k) => m.delete(k), m }; };

test('progressStore keeps the highest step and the done flag under one key', () => {
  const s = memory(); const p = progressStore(s);
  assert.equal(p.get('scholars-mate'), null);
  p.set('scholars-mate', { step: 3, done: false });
  p.set('scholars-mate', { step: 2, done: false });           // never lowers
  assert.deepEqual(p.get('scholars-mate'), { step: 3, done: false });
  p.set('scholars-mate', { step: 17, done: true });
  p.set('scholars-mate', { step: 4, done: false });           // never clears done
  assert.deepEqual(p.get('scholars-mate'), { step: 17, done: true });
  assert.deepEqual(JSON.parse(s.getItem(PROGRESS_KEY)), { 'scholars-mate': { step: 17, done: true } });
  p.reset('scholars-mate');
  assert.equal(p.get('scholars-mate'), null);
});

test('progressStore survives a throwing or missing storage', () => {
  const bad = { getItem() { throw new Error('quota'); }, setItem() { throw new Error('quota'); }, removeItem() { throw new Error('quota'); } };
  const p = progressStore(bad);
  assert.doesNotThrow(() => p.set('x', { step: 1, done: false }));
  assert.equal(p.get('x'), null);
  assert.equal(progressStore(undefined).get('x'), null);
  const corrupt = memory(); corrupt.setItem(PROGRESS_KEY, '{not json');
  assert.equal(progressStore(corrupt).get('x'), null);
});
```

### Task 2: `lessons.js` — resolving steps, open views, the Next gate

**Files:**
- Modify: `lessons.js`
- Test: `tests/lessons.test.js`

**Interfaces:**
- Produces: `resolveSteps(lesson, positions) -> Array<Step>` where `Step = { index (1-based), source: { kind: 'fen', fen } | { kind: 'pgn', pgn, ply }, view, sq: string|null, solve: boolean, task: string|null, flip: boolean, shapesGate: boolean, say }` — `same: true` copies only the previous step's `source` (a step `ply` overrides); `pos` resolves through `positions` (fen → `{kind:'fen'}`, pgn → `{kind:'pgn', ply: entry.ply}`, a step `ply` overrides); the entry's `view` is never used; throws `Error('lesson <id> step <n>: <reason>')` on a missing `pos`.
- Produces: `openViews(steps, index, done: boolean) -> Set<string>` — the views of steps 1..index; `done === true` returns the set of all nine view keys (`ALL_VIEWS` exported).
- Produces: `nextGate(step, now: { tab, ply, shapesReveal }) -> null | { kind: 'view'|'reveal'|'shapes', text }` with texts `Open <Title> first` (titles from an exported `VIEW_TITLES` map identical to the page's tab titles), `Press ▶ first`, `Press Reveal pieces first`; checked in that order.

- [ ] **Step 1: Write the failing tests**

```js
import { resolveSteps, openViews, nextGate, ALL_VIEWS } from '../lessons.js';

const positions = [{ id: 'opera-game', pgn: '1. e4 e5', ply: 2, view: 'roads' }, { id: 'lucena', fen: '1K1k4/1P6/8/8/8/8/r7/2R5 w - - 0 1', view: 'roads' }];
const lesson = { id: 't', steps: [
  { pgn: '1. e4 e5 2. Bc4 Nc6 3. Qh5', ply: 5, view: 'board', say: 'a' },
  { same: true, view: 'kings', say: 'b' },
  { same: true, ply: 3, view: 'roads', sq: 'c4', say: 'c' },
  { pos: 'opera-game', view: 'territory', sq: 'f7', say: 'd' },
  { pos: 'lucena', view: 'board', solve: false, say: 'e' },
  { pgn: '1. e4 e5 2. Bc4 Nc6 3. Qh5 Nf6 4. Qxf7#', ply: 6, view: 'board', solve: true, task: 'Find the strike', say: 'f' },
  { same: true, view: 'shapes', shapes: { gate: true }, flip: true, say: 'g' },
] };

test('resolveSteps: same copies only the position, pos uses the step view, overrides apply', () => {
  const s = resolveSteps(lesson, positions);
  assert.deepEqual(s[1].source, { kind: 'pgn', pgn: '1. e4 e5 2. Bc4 Nc6 3. Qh5', ply: 5 });
  assert.equal(s[1].sq, null);
  assert.equal(s[2].source.ply, 3); assert.equal(s[2].sq, 'c4');
  assert.deepEqual(s[3].source, { kind: 'pgn', pgn: '1. e4 e5', ply: 2 }); assert.equal(s[3].view, 'territory');   // not the entry's roads
  assert.deepEqual(s[4].source, { kind: 'fen', fen: '1K1k4/1P6/8/8/8/8/r7/2R5 w - - 0 1' });
  assert.equal(s[5].solve, true); assert.equal(s[5].task, 'Find the strike');
  assert.equal(s[6].solve, false); assert.equal(s[6].task, null); assert.equal(s[6].shapesGate, true); assert.equal(s[6].flip, true);
  assert.equal(s[0].flip, false); assert.equal(s[0].index, 1); assert.equal(s[6].index, 7);
  assert.throws(() => resolveSteps({ id: 'x', steps: [{ pos: 'nope', view: 'board', say: '' }] }, positions), /lesson x step 1/);
});

test('openViews grows with the steps and opens everything once done', () => {
  const s = resolveSteps(lesson, positions);
  assert.deepEqual([...openViews(s, 1, false)], ['board']);
  assert.deepEqual([...openViews(s, 3, false)].sort(), ['board', 'kings', 'roads']);
  assert.equal(openViews(s, 1, true).size, ALL_VIEWS.length);
});

test('nextGate: view first, then the reveal, then the shapes reveal', () => {
  const s = resolveSteps(lesson, positions);
  assert.deepEqual(nextGate(s[1], { tab: 'board', ply: 5, shapesReveal: false }), { kind: 'view', text: 'Open King houses first' });
  assert.equal(nextGate(s[1], { tab: 'kings', ply: 5, shapesReveal: false }), null);
  assert.deepEqual(nextGate(s[5], { tab: 'board', ply: 6, shapesReveal: false }), { kind: 'reveal', text: 'Press ▶ first' });
  assert.equal(nextGate(s[5], { tab: 'board', ply: 7, shapesReveal: false }), null);
  assert.deepEqual(nextGate(s[6], { tab: 'shapes', ply: 6, shapesReveal: false }), { kind: 'shapes', text: 'Press Reveal pieces first' });
  assert.equal(nextGate(s[6], { tab: 'shapes', ply: 6, shapesReveal: true }), null);
});
```

test('library: lessons are well formed', () => {
  assert.ok(Array.isArray(lib.lessons) && lib.lessons.length >= 1);
